## Project Description
This project is an end-to-end Machine Learning pipeline developed by Team PyPython (Group IT-2513) for automated residential real estate valuation.

Using regional socio-demographic data and structural property attributes (such as average area income, house age, and number of rooms), we trained a Linear Regression model to predict market house prices. The project covers the full development cycle: data preprocessing, exploratory data analysis, model training, accuracy evaluation (R² score), and features an interactive console interface for real-time price estimation.

## How to Run
1.Clone the repository to your local machine.
2.Install the required dependencies:
```bash
pip install -r requirements.txt
python src/main.py
```
3.Launch Jupyter Notebook in the project directory:
```bash
jupyter notebook
```
4.Open HousePricePrediction.ipynb and click Run -> Run All Cells.
5.Scroll to the bottom of the notebook to interact with the trained model via the console interface (enter a house index to generate a valuation report).
